# Medicullum

Website for Medicullum, an overseas medical and higher education consultancy
guiding Indian students to accredited universities in Bulgaria.

Static HTML/CSS/JS site (Tailwind via CDN, no build step). Deployed with
GitHub Pages at [medicullum.com](https://medicullum.com).

See `BLUEPRINT.md` for the design system, page wireframes, SEO structure and
production handoff notes.
